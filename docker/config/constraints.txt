# Constraints for the MWAA local-runner image (Apache Airflow 3.2.1 / Python 3.12).

# Pins the exact dependency closure the image installs (apache-airflow[celery,statsd]==3.2.1,
# the base providers in mwaa-base-providers-requirements.txt incl. fab + standard, celery[sqs],
# psycopg2, pycurl, watchtower, poetry, wheel, cached-property). Versions for the airflow +
# provider stack come from the official Airflow 3.2.1 constraints

# Airflow 3.2.1 -- do NOT bump provider versions beyond these without verifying runtime
# compatibility.
#

# which floods the GitHub dependency graph / Dependabot with alerts for packages this image
# never installs.
#
# To regenerate (requires `uv` and network access): resolve the install targets above with
#   uv pip compile --python-version 3.12 \
#     --constraint https://raw.githubusercontent.com/apache/airflow/constraints-3.2.1/constraints-3.12.txt
