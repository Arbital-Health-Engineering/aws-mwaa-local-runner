# Constraints for the MWAA local-runner image (Apache Airflow 2.11.0 / Python 3.12).

# Airflow 2.11.0 constraints (constraints-2.11.0/constraints-3.12.txt), i.e. the versions

# fail on 2.11, e.g. ModuleNotFoundError: airflow.providers.common.compat.sdk).
#
# This intentionally does NOT vendor the full upstream constraints universe (~700 packages),
# which floods the GitHub dependency graph / Dependabot with alerts for packages this image
# never installs.
