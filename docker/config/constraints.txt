# Constraints for the MWAA local-runner image (Apache Airflow 3.3.1 / Python 3.12).

# Pins the exact dependency closure the image installs (apache-airflow[celery,statsd]==3.3.1,

# provider stack come from the official Airflow 3.3.1 constraints

# compatibility.
#

# which floods the GitHub dependency graph / Dependabot with alerts for packages this image
# never installs.
#

#   uv pip compile --python-version 3.12 \
#     --constraint https://raw.githubusercontent.com/apache/airflow/constraints-3.3.1/constraints-3.12.txt
